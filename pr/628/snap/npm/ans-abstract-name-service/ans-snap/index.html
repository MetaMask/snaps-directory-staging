Description by ANS | Abstract Name Service

ANS | Abstract Name Service enables native .abs name resolution inside MetaMask on Abstract (chain ID 2741). Features: - Forward lookup: resolves name.abs -> address using ANS V2 records. - Reverse lookup: resolves address -> primary .abs name when available. - Owner fallback: if no resolver record exists, falls back to ANS ownership data. How to use: 1. Connect wallet on the companion site. 2. Install the Snap. 3. In MetaMask, send assets using a .abs name (for example: shroomy.abs). Network scope: - Abstract mainnet only (eip155:2741).
